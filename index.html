Help: how to use JD Fit Checker

What this tool does

It screens a job description (JD) you paste against your own resume versions and gives an honest verdict, a fit %, a keyword (ATS-style) match and the closest resume to send. When it is worth it, it can generate a minimally tailored copy of that resume without inventing claims. It runs locally on this computer: your data stays on your machine.

Quick start for a new user

  1. Try the Demo profile (sidebar, Profile) and click Analyze on a sample JD to see a full result.
  2. Create your profile with Create profile: a name and an optional password.
  3. Upload your resume versions (.docx) or paste their text. PDF is not supported yet. New profiles do this in Create profile step 2; later versions go in Profile settings, "Upload new version".
  4. Review the drafted profile (years, education, certifications, skills) and correct anything wrong (Create profile step 3).
  5. Set the directions to target or avoid, the seniority ceiling and the tailor band (default 20) in Create profile step 4. The apply threshold (default 75) can be changed at any time in the sidebar.
  6. Paste a JD (or a posting URL; LinkedIn and sites behind a login need pasted text) and click Analyze.
  7. Read the verdict. If a tailored resume is offered, generate it, apply, then answer "Did you apply?" so the application is logged.
  8. Add new skills on My evidence as you gain them, then update the resumes you pick.

Reading the results

  1. Seen before: whether you already applied, skipped or held this company or role.
  2. Verdict: Apply, Tailor, Hold or Skip, with the scores behind it.
  3. Direction check: whether the role is in a direction you target or avoid.
  4. Level check: required years and seniority against your experience.
  5. Gates: must-have requirements (certifications, tools, domains) and whether you meet them.
  6. % fit: the score with a component-by-component breakdown and any penalties.
  7. Keyword match: ATS-style coverage, with the JD highlighted: matched, missing but supportable, missing and not supported, red flag.
  8. Nearest base resume: your closest resume to send, ranked with reasons.
  9. Tailor decision: whether honest edits are worth making, and the option to generate the tailored copy.
  10. Suggested improvements: what to add (backed by evidence), what NOT to claim (prepare for the interview instead) and work samples to attach.
  11. Honesty guard: checks every suggestion against your resume text and evidence.
  12. Interview prep: likely questions with honest bridges for the gaps.
  13. Log entry: a ready-made line for your application log.

VerdictWhen

Honest edits are computed once, in a single pass: the tool never chases the threshold or inflates scores.

Tabs

  • Check a JD: analyze one job description.
  • Compare two JDs: two postings side by side.
  • History: your past checks in this profile.
  • Calibration: sample roles scored against their expected results, to check the scoring.
  • Resume repository: every resume with its type (base, submitted copy, variant), lineage, staleness and recency (newer wins a tie).
  • My evidence: add skills you can honestly claim; a pick list (with Select all) updates the resumes that lack one. Submitted copies are never edited: when included they are promoted once into a _v2 variant.
  • Stats: screening and application counts, trends and common gaps.
  • Profile settings: password, reset and uploading new resume versions.
  • Help: this page.

Profiles, passwords and privacy

  • Each profile is separate: its own resumes, rules, history and log. Profiles are stored outside the tool folder, in %USERPROFILE%\.jd-fit-checker\profiles\ (or under the folder set in JDFC_HOME). The server window shows the exact path when it starts.
  • A password locks the profile and encrypts the tool's own files for it on disk. An unlocked profile locks again after 30 minutes idle.
  • Honest limits: there is no recovery for a forgotten password (you would reset the profile); it does not protect against an administrator on the same computer; resume .docx files and linked files outside the profile folder are not encrypted.

Troubleshooting

  • A button seems to do nothing: read the message right under it.
  • "Profile is locked": use Unlock in the sidebar.
  • "Paste a JD or a posting URL": the JD box is empty.
  • "Analyze timed out" or "Fetch timed out": the server may be busy or stopped; check the server window, then try again.
  • After an update, press Ctrl+F5 to reload the page.
  • Fetching a URL says to paste instead (for example LinkedIn): copy the JD text from the page and paste it.
  • "Part of the page failed to load" banner: press Ctrl+F5; details are in the browser console (F12).

FAQ

Why is my fit lower than I expected?
Scoring is strict, like a recruiter's first screen. If it is too strict for you, adjust the apply threshold in the sidebar.
Why won't it add a skill I have?
Add it on My evidence first. The honesty guard only uses your resume text and your evidence.
Does it send my resume anywhere?
No. The only outbound request is fetching a posting URL you enter.
Can I use it on another computer?
Yes: copy the tool folder and, separately, your profile folder.
